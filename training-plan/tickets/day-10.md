# Day 10: Review & quality

**Labels:** `training` `day-10` `phase::dev-track` · **Source:** https://dojo.agilityio.dev/schedule/day-10.html

## Goal
Use Claude for code review and security checks, and judge the signal.

## Tasks
- [ ] Run `/code-review` on a real branch.
- [ ] Run ultrareview (`/code-review ultra`) on the seeded-buggy branch from the lead; compare the signal with `/code-review`.
- [ ] Walk through the security plugins (security-guidance, Claude Security scan).
- [ ] Fix what the review found and get the PR green.
- [ ] List false positives for the retro.

## Deliverables
- Review reports and the green PR.
- False-positive list.

## Definition of Done
- [ ] Each finding is fixed or explicitly dismissed with a reason.
- [ ] Notes in `exercises/day-10-exercises.md`; 3 takeaways written.
