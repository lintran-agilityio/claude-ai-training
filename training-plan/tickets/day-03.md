# Day 3: Fix, review, merge (Checkpoint 1)

**Labels:** `training` `day-03` `phase::fundamentals` `checkpoint` · **Source:** https://dojo.agilityio.dev/schedule/day-03.html

## Goal
Fix the Day 2 bug, open a clear PR, review a peer's PR, and merge.

## Tasks
- [ ] Fix the Day 2 bug on a branch with small commits and a test.
- [ ] Write the PR description (what, why, how tested, screenshots). Draft with Claude, edit by hand. Open the PR.
- [ ] Peer swap: read another PR and say whether you could implement or review it from the description alone.
- [ ] Review your partner's PR using the checklist in order: correctness, tests, readability, basic security, scope. Leave at least 3 actionable comments.
- [ ] Resolve the seeded conflict on your PR, merge, and delete the branch.

## Checkpoint 1 (must pass)
- [ ] Bug reproduced and repro recorded in the ticket.
- [ ] Fix on a branch with a test.
- [ ] PR with a self-contained description.
- [ ] One peer review with 3 actionable comments, and one merge with the conflict resolved.

> If any item fails, repeat it as homework during Days 4–5.

## Definition of Done
- [ ] Checkpoint 1 all green; evidence linked in `exercises/day-03-exercises.md`.
- [ ] 3 takeaways written.
