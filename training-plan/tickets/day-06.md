# Day 6: Flagship & parallel (Checkpoint 2)

**Labels:** `training` `day-06` `phase::dev-track` `checkpoint` · **Source:** https://dojo.agilityio.dev/schedule/day-06.html

## Goal
Use Claude Code's flagship features and run work in parallel.

## Tasks
- [ ] Artifacts: publish a PR walkthrough artifact and share it with a peer.
- [ ] `/loop`: run `/loop 15m` on your open PR, then `/loop 5m check the deploy`. Write a `loop.md` for the repo.
- [ ] Remote Control: start a session with `/rc`, connect from your phone (claude.ai/code), and send one steer.
- [ ] Ultracode family: use `ultrathink` on a hard bug; compare results at different `/effort` levels.
- [ ] Parallel sessions: two tickets in separate git worktrees (`claude --worktree ticket-123`); watch both in agent view.
- [ ] Subagents and cloud: finish the *Introduction to subagents* course; start a cloud session for a long task and check it later from claude.ai/code.
- [ ] Post screenshots to the channel: artifact, loop run, phone steer.

## Checkpoint 2 (must pass)
- [ ] Two parallel sessions, both merged.
- [ ] One plan-mode change steered via diff comments.
- [ ] One artifact.
- [ ] One Remote Control steer.
- [ ] One `/loop` run.

## Definition of Done
- [ ] Checkpoint 2 all green; evidence in `exercises/day-06-exercises.md`; 3 takeaways written.
