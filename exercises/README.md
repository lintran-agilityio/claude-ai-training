# Exercises

Hands-on work that runs through the whole 15-day training. It has two parts:

| Part | Where | What |
| --- | --- | --- |
| Daily exercises | `day-XX-exercises.md` | Evidence and notes for each day's ticket in [../training-plan/tickets/](../training-plan/tickets/README.md). |
| Practice project | [manage-homestay/](manage-homestay/) | A homestay booking app with an AI assistant (CopilotKit + LangChain + LangGraph), built step by step as the training progresses. |

## Manage Homestay

Start here: [manage-homestay/project-instructions.md](manage-homestay/project-instructions.md) (English and Vietnamese). It is the Claude Project instructions that set Claude up as engineer, mentor and BA/QA for this app.

User features: login, view rooms, ask AI, book a room, edit a booking, delete a booking, find a room.

Suggested way to use it across the training:

| Training phase | What to do on the project |
| --- | --- |
| Days 1-3 (Fundamentals) | Create the Claude Project, paste the instructions, ask Claude to analyze the 7 features and split them into tasks. |
| Days 4-11 (Dev track) | Build features task by task with Claude Code; add memory (CLAUDE.md), skills, MCP and hooks to the project as you learn them. |
| Days 12-15 (Capstone) | Test, harden, review and demo the app. |

Rules from the main README still apply: sample data only, no real secrets, read every diff.
