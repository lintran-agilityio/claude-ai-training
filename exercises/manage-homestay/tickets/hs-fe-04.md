# HS-FE-04: Room detail page

**Labels:** `homestay` `hs-fe-04` `phase::mvp-core` `layer::frontend` `P0` · **Estimate:** M · **Priority:** P0
**Depends on:** HS-FE-03 · **Source:** [tickets.md](../tickets.md)

## Goal
Photo gallery, description, amenities, price, capacity, availability checker (dates + guests), and a "Book" entry point.

## Acceptance criteria
- [ ] Given a room, then all info shows; unknown id shows a 404 page.
- [ ] Given I pick dates, then availability and total price display.
- [ ] Given unavailable dates, then the Book button is disabled with a reason.

## Definition of Done
- [ ] Code reviewed and merged via MR.
- [ ] Tests written and passing in CI.
- [ ] Acceptance criteria above met and demonstrated.
- [ ] No secrets in code; `.env.example` updated if needed.
- [ ] README / API docs updated.
