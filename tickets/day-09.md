# Day 9: Hooks & automation

**Labels:** `training` `day-09` `phase::dev-track` · **Source:** https://dojo.agilityio.dev/schedule/day-09.html

## Goal
Automate repeated checks with hooks, goals, and routines.

## Tasks
- [ ] Build one hook (format-on-edit, block-forbidden-command, or notify-on-finish) and ship it as a PR.
- [ ] Automation ladder:
  - [ ] `/goal` on a bounded task.
  - [ ] Desktop scheduled task (Code tab → Routines → New routine → Local), e.g. a morning briefing.
  - [ ] Cloud routine at claude.ai/code/routines.
  - [ ] Install `@claude` on GitHub with `/install-github-app`.
- [ ] Exercise: let `@claude` review your next PR and evaluate its comments.

## Deliverables
- Merged PR with the hook.
- Evaluation of `@claude` review comments.

## Definition of Done
- [ ] The hook fires on the intended event.
- [ ] Notes in `exercises/day-09-exercises.md`; 3 takeaways written.
