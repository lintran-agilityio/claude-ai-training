# Day 4: Install & daily loop

**Labels:** `training` `day-04` `phase::dev-track` · **Source:** https://dojo.agilityio.dev/schedule/day-04.html

## Goal
Install the Claude Code Code tab and run the ticket-to-PR loop.

## Tasks
- [ ] Install and verify the desktop Code tab on the training repo. Learn the sidebar, resume (`/resume`), and one topic per session.
- [ ] Try the permission modes (`default`, `acceptEdits`, plan, auto) on a throwaway change.
- [ ] Ask Claude to "explain how feature X works", then verify 2 of its claims by reading the code.
- [ ] Take a bug ticket through the full loop: paste ticket → plan mode → approve plan → implement → steer with a diff hunk comment → run tests → open PR.
- [ ] Repeat with a second ticket, without help.
- [ ] Read: Claude Code 101, quickstart, common workflows, best practices.

## Deliverables
- Feature X explanation with 2 verified claims.
- Two PRs created through the loop.

## Definition of Done
- [ ] Both loops completed; notes in `exercises/day-04-exercises.md`.
- [ ] 3 takeaways written.
