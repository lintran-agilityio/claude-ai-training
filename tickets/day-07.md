# Day 7: Skills & plugins

**Labels:** `training` `day-07` `phase::dev-track` · **Source:** https://dojo.agilityio.dev/schedule/day-07.html

## Goal
Package repeated work into skills, commands, and plugins.

## Tasks
- [ ] Finish the course *Introduction to agent skills*.
- [ ] Write one team skill (e.g. `release-checklist`, `how-we-write-migrations`) and one personal slash command.
- [ ] Ship both via a PR to the repo's `.claude/`.
- [ ] Open `/plugin` → Discover, install one useful plugin (e.g. code-intelligence/LSP), and evaluate it honestly.

## Deliverables
- Merged PR with the team skill and the slash command.
- Plugin evaluation note (what it did well, what it missed).

## Definition of Done
- [ ] The skill runs when invoked.
- [ ] Notes in `exercises/day-07-exercises.md`; 3 takeaways written.
