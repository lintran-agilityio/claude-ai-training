# Day 12: Capstone: kickoff and planning

**Labels:** `training` `day-12` `phase::capstone` · **Source:** https://dojo.agilityio.dev/schedule/day-12.html

## Goal
Start the mini-product. The lead plays the client; Devs ask questions through tickets only.

## Tasks
- [ ] Attend the lead's feature briefing (intentionally vague).
- [ ] Read the BA ticket pack (story + Given/When/Then + open questions).
- [ ] Ask your questions **only through the tickets**, using Claude to find gaps first.
- [ ] Check the ticket pack against the zero-questions test: could you build it without asking more?
- [ ] Leads only: finish the AI-native SDLC playbook.

## Deliverables
- Questions logged on the tickets.
- A short note: what was unclear and how it was resolved.

## Definition of Done
- [ ] Every ticket you will build has no open questions.
- [ ] 3 takeaways written.
