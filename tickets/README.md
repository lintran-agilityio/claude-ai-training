## Conventions

- **Labels:** `training`, `day-XX`, `phase::fundamentals | dev-track | capstone`, plus `checkpoint` where it applies.
- **Evidence:** screenshots, links, or notes go in `exercises/day-XX-exercises.md`.
- **End of day:** add 3 takeaways in your own words (see the README working rules).
- **Source of truth:** if the Dojo page changes, the Dojo page wins; update the ticket.
- **Import to GitLab:** run `scripts/create-issues.ps1` (needs `glab`) to create all 15 issues from these files.
