**Labels:** `training` `day-15` `phase::capstone` `checkpoint` · **Source:** https://dojo.agilityio.dev/schedule/day-15.html

## Goal
Ship the capstone end-to-end and capture what to keep.

## Tasks
- [ ] Cross-review: review QA's test code; have QA review your PR.
- [ ] Merge, tag a release, and run the deploy.
- [ ] Remote Control / Dispatch demo: approve and steer a session from your phone.
- [ ] Pair demo (10 min): show the flow, not slides: ticket → plan → PR → review → tests → artifact → shipped.
- [ ] Retro: file each standardization item (`CLAUDE.md` rules, skills, hooks, review checklist) as a repo issue with a named owner.
- [ ] Write a one-page "how I work with Claude" playbook (workflows, prompts, guardrails) and share it.

## Final checkpoint (must pass)
- [ ] Capstone shipped end-to-end.
- [ ] Days 3 / 6 / 11 checkpoints all green.

## Definition of Done
- [ ] Release tagged, demo done, retro issues filed, playbook shared.
- [ ] 3 takeaways written.
