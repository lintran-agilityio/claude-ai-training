# Day 13: Capstone: build

**Labels:** `training` `day-13` `phase::capstone` · **Source:** https://dojo.agilityio.dev/schedule/day-13.html

## Goal
Implement the capstone tickets in parallel, with a plan approved before any code.

## Tasks
- [ ] For each ticket: start in plan mode and get the plan approved before coding.
- [ ] Work each ticket in its own isolated session on a git worktree.
- [ ] One PR per ticket, with a self-contained description.
- [ ] Read every diff and run tests before committing.
- [ ] Keep notes as you go.

## Deliverables
- One PR per ticket, with tests.
- Notes. All work is Claude-assisted and human-edited.

## Definition of Done
- [ ] You can explain every change in your PRs.
- [ ] 3 takeaways written.
