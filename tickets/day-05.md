# Day 5: Memory & context

**Labels:** `training` `day-05` `phase::dev-track` · **Source:** https://dojo.agilityio.dev/schedule/day-05.html

## Goal
Make Claude remember the project and manage long sessions.

## Tasks
- [ ] Write the repo `CLAUDE.md`: build/run commands, conventions, a "never do" list. Keep it under one screen.
- [ ] Auto memory and compaction: run a long session, compact, and note what survives (`/memory`).
- [ ] Checkpointing: make a bad edit, then undo it with `/rewind` (Esc Esc).
- [ ] Exercise: run the same task in a fresh session vs a session that already read the codebase. Compare quality and token use.

## Deliverables
- `CLAUDE.md` merged to the repo.
- Short comparison note (fresh vs informed session).

## Definition of Done
- [ ] `CLAUDE.md` contains only true, current instructions.
- [ ] Notes in `exercises/day-05-exercises.md`; 3 takeaways written.
